作业哨兵 0.1.8 使用教程
========================

一、安装
1. 从 GitHub Releases 下载 HomeworkSentinel-0.1.8-release.apk（日常使用）。
2. 如需测试新功能，可安装 HomeworkSentinel-0.1.8-debug.apk；它的包名带 .debug，可以和正式版同时存在。
3. 如果手机提示“未知来源”，按系统提示允许本次安装。
4. 最低支持 Android 10。

二、首次启动
1. 打开应用，会进入“通知访问授权”向导。
2. 点击“打开系统通知使用权设置”，在系统列表中找到“作业哨兵”并授权。
3. 返回应用，点击“刷新授权与连接状态”。
4. 点击右上角“完成”进入主界面。
5. 扫描功能还需要无障碍服务：设置 → 权限操作 → 开启无障碍服务（不授权也不影响通知采集和作业管理）。

三、收件箱与转作业
1. 底部“收件箱”会显示已采集的通知。
2. 点击一条通知可查看原文；可以复制原文。
3. 判定为作业的通知，可点“确认并转为作业”；不相关的点“不是作业”。
4. 转成作业后可在“作业”页设置截止时间、课程、说明和备注。

四、作业管理
1. 首页点击右上角“+”新建作业；标题必填，截止时间可选。
2. 截止时间只提供 5 分钟刻度，已过去的时间不能保存。
3. 作业可编辑、标记完成、删除；逾期和今天截止会单独统计。

五、扫描
1. “扫描”页可选择目标教学应用，创建扫描任务。
2. 扫描依赖通知使用权/无障碍授权；未授权时会提示先授权。
3. “设置 → 后台周期扫描”可调整周期；系统可能因省电策略延迟执行。

六、数据备份与恢复
1. 设置 → 数据管理 → 导出数据（JSON），选择保存位置。
2. 备份包含通知、作业、人工反馈、来源白名单和设置；请妥善保管。
3. 恢复只允许空数据库：恢复前会校验格式/版本/校验和并展示预览。
4. 恢复不会自动恢复系统权限，需要重新检查通知使用权等授权。
5. 卸载应用会删除本地数据库；换机或刷机前务必先导出。

七、主题
设置 → 关于上方可切换跟随系统 / 浅色 / 深色。

八、常见问题
Q：收不到通知？
A：确认系统通知使用权已授权、通知监听服务已连接；部分厂商需要在电池/后台管理里允许应用自启动。

Q：扫描没有结果？
A：确认无障碍服务已开启，且目标应用在通知监听白名单中；扫描依赖系统页面可访问性，不保证所有教学应用都支持。

Q：卸载后数据还能找回吗？
A：不能。数据只存在本机，卸载即删除；只能依赖之前导出的 JSON 备份。

Q：Debug 和 Release 有什么区别？
A：Release 是正式签名、R8 优化版；Debug 包名带 .debug、使用调试签名，便于测试，可与 Release 并存，但两者数据不互通。

Q：应用会联网或上传通知吗？
A：不会。应用未申请 INTERNET 权限，通知、作业和备份都在本机处理。

九、隐私提醒
1. 导出的备份包含通知正文、作业和备注等隐私内容，不要发到公开群聊或仓库。
2. 反馈问题时请勿附带包含个人信息的截图或备份文件。
